## О проекте

Набор сетевых утилит на Python для расчёта подсетей, планирования VLSM, проверки IP-адресов устройств и диагностики сетевых подключений.

Проект создан с использованием стандартных библиотек Python. Дополнительные зависимости не требуются.

## Состав проекта

| Файл | Назначение |
|---|---|
| `netcalc.py` | Калькулятор подсетей и VLSM |
| `audit.py` | Поиск ошибок в IP-адресах устройств |
| `netdiag.py` | Диагностика сетевого подключения |
| `services.py` | Последовательная и параллельная проверка TCP-сервисов |
| `netkit.py` | Единый интерфейс командной строки |
| `plan_v6.csv` | План адресации шестого варианта |
| `devices.csv` | Список тестовых устройств |
| `audit_report.csv` | Результаты аудита |
| `diag_log.csv` | Журнал диагностики сети |
| `tests/test_netcalc.py` | Модульные тесты |

## Исходные данные варианта 6

Базовая сеть: `192.168.200.0/24`

- Классы: 120 устройств
- Учителя: 35 устройств
- Администрация: 8 устройств
- Запас роста: 10%
- Порт локального веб-сервера: 8060

Для размещения всех подсетей с запасом роста используется расширенная сеть `192.168.200.0/23`.

## Запуск

Открыть терминал в папке проекта.

### Калькулятор подсетей

```powershell
python netkit.py calc 192.168.200.10/24
```

### Планирование VLSM

```powershell
python netkit.py vlsm 192.168.200.0/23 "Классы=120" "Учителя=35" "Администрация=8" --growth 10 --csv plan_v6.csv
```

### Аудит IP-адресов

```powershell
python netkit.py audit plan_v6.csv devices.csv --report audit_report.csv
```

### Диагностика подключения

```powershell
python netkit.py diag
```

При необходимости шлюз можно указать вручную через `--gateway`.

### Параллельная проверка сервисов

Сначала запустить локальный веб-сервер:

```powershell
python -m http.server 8060
```

В другом терминале:

```powershell
python netkit.py services --parallel --workers 10 --timeout 3
```

## Модульное тестирование

Запуск всех тестов:

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
```

Тесты проверяют расчёт подсетей, типы IP-адресов, корректность VLSM и обнаружение ошибок аудита.

## Коды завершения

`0` — команда выполнена успешно.

`1` — обнаружены ошибки аудита, проблемы подключения, недоступные сервисы или ошибки планирования.

## Особенности реализации

В процессе диагностики программа учитывает сетевые интерфейсы компьютера. Для тестирования использовались Wi-Fi, Radmin VPN и мобильная точка доступа.

В файле `devices.csv` намеренно содержатся некорректные данные, необходимые для проверки аудитора.
